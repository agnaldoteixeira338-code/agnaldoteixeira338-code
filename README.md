### 🚀 Projeto em destaque

**[FIDELI+](https://github.com/agnaldoteixeira338-code/fideliplus)**: sistema de fidelização de clientes para comércios.
[Demo ao vivo](https://fideli-client.onrender.com)

- API REST em **Node.js/Express** e front-end em **React**
- Banco **PostgreSQL** com 7 tabelas, modelado com SQL puro (sem ORM)
- Login real com **JWT + bcrypt** e acesso por perfil (cliente e dono)
- Descontos progressivos calculados automaticamente a cada visita
- Deploy em produção: **Render** (API + front) e **Neon** (banco)
